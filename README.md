One-line haunted server-room door sign entry for the make.fun bounty
[Funniest Sign on a Haunted Server Room Door](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a).

`main.py` (Python 3 stdlib only) writes a single door sign
to `/output/entry.txt` — 70 characters, one line, UTF-8, no
trailing newline.

## Files

- `main.py` — the entry (stdlib-only copier)
- `README.md` — this file
- `LICENSE` — MIT

## Run

```sh
python3 -P -s main.py
```
